# 二创改写与降重

输入已有文本,输出自然流畅、去 AI 味、与原表达区分开的新版本。**只优化表达方式,不改变事实、观点和数据。**

## 这个 skill 解决什么

- AI 写的稿子查重率 60%+,需要降到安全区间再发布。
- 已有素材要做二创,但直接改几个词还是「一眼同源」。
- 工作汇报 / 公众号稿读起来「一股 AI 味」,领导或读者一眼看穿。

## 执行流程

### 第一步:诊断(24 类特征扫描,每项 0-3 分,满分 72)

**结构类(最易被检测):**
1. 过度使用「首先、其次、最后、此外、总之」
2. 每段长度过于均匀
3. 列表和编号过多
4. 开头总括句 + 结尾总结句的固定模式

**词汇类:**
5. 「值得注意的是」「需要指出的是」等套话
6. 形容词过于精确、丰富
7. 大量「以及」「与此同时」「在这个过程中」
8. 缺少口语化和个人化用词

**语气类:**
9. 全篇语气均匀、客观、无个性
10. 缺少犹豫和不确定的表达
11. 没有瑕疵、口语、不完美
12. 过于面面俱到,缺少取舍

**逻辑类:**
13. 论证过于对称
14. 每个观点都跟「例如」+ 完美例子
15. 缺少思维跳跃和个人经验
16. 结论过于安全、中庸

**场景类(论文 / 深度长文专用):**
17-24. 引用格式过统一、文献综述像列清单、方法描述过于流畅、讨论过于圆满、高频被动语态、术语过于一致、缺少第一人称表达、段落过渡过于顺滑

**评分分级:**

- 0-15:轻微 → 简单润色
- 16-35:中度 → 系统改写
- 36-72:重度 → 深度重构

### 第二步:选改写强度

| 强度 | 适用 | 操作 | 预计降重 |
|------|------|------|---------|
| 轻度 | 0-15 分 | 替换套话,加 2-3 处个人表达 | 5-10% |
| 中度 | 16-35 分 | 重写过渡句,替换 30% 句式 | 15-25% |
| 深度 | 36-72 分 | 保留观点,完全重写句子 | 25-40% |

### 第三步:改写原则

**原则一:加入人味**

- 偶尔短句(「没错。」「就这么简单。」)
- 加入体感(「我第一次看到这个数据也很惊讶」)
- 用具体替代抽象(「效果很好」→「三天涨了 2000 粉」)

**原则二:打破均匀**

- 段落长短交替(长段 150 字 + 短段 30 字)
- 有的详展,有的一笔带过
- 偶尔插入联想或比喻

**原则三:去掉安全感**

- 删掉万金油结论
- 给出明确判断
- 承认不确定

**原则四:二创要「换骨架」**

- 不只换同义词,还要换切入角度、论证顺序、举例方式
- 合并或拆分原句的信息密度
- 把「总-分-总」改成「从具体场景切入再归纳」

**原则五(论文 / 长文专用):**

- 「笔者/本文认为」替代高频被动语态
- 文献引用写得像跟前人对话,而不是列清单
- 研究局限写得真诚
- 引用格式和数据准确性必须保留

### 第四步:输出

```
【诊断结果】
AI 痕迹评分:XX/72(轻微/中度/重度)
主要问题:[前 3 个最严重特征]
改写强度:轻度/中度/深度

【改写后文本】
[完整改写后文本]

【变化说明】
- 替换 XX 处连接词
- 调整 XX 处段落结构
- 增加 XX 处个人化表达
- 预计查重率:约从 XX% 降至 XX%

【注意】查重率为经验值,建议改写后用目标系统验证。
```

### 第五步:质量检查

- [ ] 核心观点保留?
- [ ] 引用和数据准确?
- [ ] 读起来自然?
- [ ] 学术格式保留?
- [ ] 与原文表达区分开了?

## 使用建议

- 一次处理一个段落 / 章节,别整篇一次性糊。
- 改写后自己通读一遍,补进个人用词习惯。
- 论文改写后先跑一次查重验证再定稿。
- 自媒体二创注意素材合规,尊重原作者署名与平台规则。

## 使用须知

- 本 skill 是文风优化工具,帮助改善 AI 生成文本的自然度,并辅助合法改写。
- 论文的核心思想、研究方法、数据分析必须是作者本人的原创工作。
- 不鼓励学术不端或抄袭规避;使用者须遵守所在机构与平台的诚信规定。
- 改写不改变事实和观点,只优化表达方式。
