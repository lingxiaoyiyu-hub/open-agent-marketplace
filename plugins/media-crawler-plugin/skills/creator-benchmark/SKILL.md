# Creator Benchmark | 竞品大V对标分析协议

本技能指导 Agent 如何对指定创作者/对标账号的历史高赞爆款进行全量复盘与画像诊断。

## 分析维度

1. **爆款率与产能模型**：
   - 统计周期内的总发文数、万赞爆款占比、平均互动量。
   - 分析发文黄金时段（早间 7:00、午间 12:00、晚间 20:00 等）。

2. **选题象限图**：
   - 高互动低门槛题材（吸粉引流型）
   - 高转发强观点题材（口碑破圈型）
   - 高转化带货/付费题材（商业变现型）

3. **高频词云与视觉风格**：
   - 提取对标大V标题高频词汇（如：揭秘、千万别、真实内幕、后悔没早看）。
   - 封面排版风格（大字报、情绪特写、对比图、极简风）。

4. **产出诊断报告**：
   - 输出包含《对标大V核心优势清单》、《可直接借鉴的爆款选题池》与《差异化超车策略建议》的结构化报告。
