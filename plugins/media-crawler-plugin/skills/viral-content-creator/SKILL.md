# Viral Content Creator | 爆文拆解与矩阵重构改写协议

本技能指导 Agent 如何对采集到的 10w+ 爆款文章进行微观结构拆解，并以“去 AI 味、强情绪共鸣、黄金开头”标准进行矩阵式二次创作。

## 爆款结构四步拆解法 (AIDA+)

1. **黄金 3 秒钩子 (Hook)**：
   - 制造反常识认知（“工作十年才明白，老板最讨厌的员工不是笨蛋，而是...”）
   - 抛出尖锐矛盾（“公婆偷偷把 80 万拆迁款全给了小叔子，三年后登门要求...”）
   - 利益与好奇关联（“头条今年调整了微头条单价算法，很多人第一步就做错了”）

2. **情绪主线 (Emotional Tension)**：
   - 委屈 -> 隐忍 -> 反击（爽点）
   - 困惑 -> 探索 -> 领悟（成长）
   - 争议点设计：文章中间必须埋入 1~2 个能够激发读者在评论区站队讨论的争论点。

3. **金句提炼与节奏排版**：
   - 每段不超过 3 行，多用短句，杜绝长难复合句。
   - 关键转折处单独成段并**加粗显示**。
   - 严禁出现 AI 机械连接词（如“首先、其次、综上所述、总而言之”）。

4. **结尾互动钩子 (Call to Action)**：
   - 抛出开放式反问（“如果你遇到这种情况，会选择原谅还是直接拉黑？”）。
   - 引导读者留下自己的经历与地区民俗。

## 跨平台重构适配矩阵

- **今日头条微头条**：500~800 字，强故事冲突，口语化，适合中老年与社会大众。
- **小红书图文笔记**：300~500 字，Emoji 视觉排版，提取 5~8 个高频搜索 Tag，突出生活方式与精致感。
- **知乎长回答**：1500~3000 字，第一人称沉浸式叙述，夹叙夹议，逻辑层次丰富。
- **短视频口播文案**：60~90 秒时长，语速节奏提示，镜头景别标注。
